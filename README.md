# Smart Loan Eligibility & Management System

## Overview

The Smart Loan Eligibility & Management System is a Flask-based web application developed to evaluate loan applications based on applicant information such as income, credit score, loan amount, and existing loans.

The application predicts loan eligibility, calculates EMI, classifies risk levels, and stores customer and loan application records using an SQLite database.

---

## Features

- Loan eligibility prediction
- EMI calculation
- Risk classification
- Customer management
- Loan application management
- Admin dashboard
- SQLite database integration

## How to Run

1. Clone the repository.

```
git clone https://github.com/YOUR_USERNAME/Smart-Loan-Eligibility-System.git
```

2. Install the required libraries.

```
pip install -r requirements.txt
```

3. Run the application.

```
python app.py
```

4. Open your browser and visit

```
http://127.0.0.1:5000
```
